## 定义

> [热词] 社区热词，未经沉淀，信息可能快速过时

模型数据总览是把各家大模型（LLM）的**性能、价格、速度、上下文窗口、开放度**等关键指标放在同一张表里对比的速查页。数据来自 Artificial Analysis（独立第三方评测机构），它不卖模型、不站队，专门用统一的标准跑各家 API，把"哪个模型又快又好又便宜"这件事量化出来。这张表解决的是选型问题：同样是 100 万 token 上下文、同样是顶级智能,为什么 A 家收 $0.2、B 家收 $5?这张表给你答案。

## 原理

### 数据怎么来的

Artificial Analysis 用自己的评测套件（Intelligence Index v4.1.1,包含 9 项评测:GDPval-AA、GPQA 等）跑各家模型的官方 API,然后加权算出一个**智能指数**（Intelligence Index,0-100 分制,越高越聪明）。它衡量的是"推理能力"这个综合概念,而不是单一基准的分数。

总览里每个指标的含义：

| 指标 | 含义 | 越高越好？ |
|------|------|-----------|
| 智能指数 | 9 项评测加权综合分,衡量推理/知识综合能力 | [OK] 越高越好 |
| 输出速度 | 每秒输出多少 token（tok/s） | [OK] 越高越好 |
| 输入/输出价 | 每百万 token 的美元价格（API 调用） | [否] 越低越好 |
| 上下文窗口 | 模型一次能"记住"的最大 token 数 | [OK] 越大越好 |
| 开放度 | 模型权重是否开源及开放程度（0-100） | [OK] 越高越开放 |
| 全知指数 | 知识可靠性/幻觉指数,奖励"知之为知之" | [OK] 越高越可靠 |

### 注意两个细节

- **价格是"官方 API 价"**：同一模型在不同厂商（如 Groq、Together）部署,价格和速度可能差很多,这张表只反映官方或主流 API 的典型值。
- **速度受硬件影响**：输出速度是评测时的实测值（中位数）,厂商升级硬件或优化推理后数字会变,所以标为"热数据"。

## 由来与历史

Artificial Analysis 成立于 2023 年,创始团队来自 AI 基础设施背景。2024-2025 年 AI 模型爆发式增长,各家模型宣称的能力互相矛盾（"我们最强"满天飞),市场上缺少一个**独立、统一、可重复**的对比口径——AA 填补了这个空白。它的 Intelligence Index 从 v3 迭代到 v4.1.1,不断纳入新评测（如 agentic 能力的 AA-Briefcase Elo、知识可靠性的 AA-Omniscience Index）。中文社区（机器之心、量子位等）常引用它的数据来佐证"哪家模型登顶"的报道,是业界引用率最高的第三方横评之一。

## 应用

选型时三步走:

1. **先圈智能档位**：看智能指数,确定你需要的"聪明程度"区间（比如 50+ 是顶级旗舰,40-50 是主流,35 以下偏轻量）。
2. **再比价格速度**：同档位里挑性价比——比如 GLM-5.2（52.6 分、$1.4/$4.4）和 GPT-5.6 Terra（56.6 分、$2/$12）,前者便宜近一半、速度还快。
3. **看上下文和开放度**：长文档任务必须有 1M 上下文;要本地部署/私有化就只能选开放度高的开放权重模型。

## 争议 / 讨论

- **智能指数不等于真实任务表现**：它是对 9 项评测的加权平均,权重是 AA 自己定的;换个权重,排名可能变。对特定任务（比如长代码、中文写作）,单看总分会误导。
- **"官方 API"的口径偏差**：Claude Fable 5 显示"with fallback"、许多模型没有价格数据,说明 AA 对部分模型的评测是降级口径（没有官方 API 时用第三方部署的中间值）,横向对比会失真。
- **价格波动快**：2025-2026 年模型价格跳水是常态（如 Nemotron 3.5 Lightning 只要 $0.05/$0.2）,这张表只能反映抓取时刻的快照,用之前看采集日期。
- **"—"表示未测或未公开**：很多模型不是每个指标都有数据（未开放 API、未跑完评测等),不要解读为 0 或很差。
