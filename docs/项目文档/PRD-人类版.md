# PRD — AI 知识库（人类版）

> 版本：v1.1 ｜ 日期：2026-08-15
> 一句话：**一线知识的沉淀与导航站** —— 开源、Wiki 式、面向所有人的知识库。以 AI 为主体，可扩展到任意领域。

---

## 这是什么

把 AI 领域的概念讲清楚的地方。每个词条是一个独立页面，点击跳转，互相链接——像一本不断生长的、开放给所有人编写的 AI 词典。

**它和普通词典的区别**：
- 从**底层原理**长出来（先有根，再有枝，最后是叶），不是散装词条堆砌
- 内容**来自社区一线**（论文/官方课程/讨论），不靠 AI 闭门造车
- 每个人都能**贡献**（纠错、写词条），像开源项目一样生长

## 设计逻辑（四根柱子）

-  **上限靠来源**：每条都带原始链接，无源不收录
-  **标准靠校验**：词条有规范模板，机器自动检查
-  **生态靠开放**：任何人可以提交、纠错、讨论
-  **信任靠留痕**：谁写的、什么时候、改过几次，全部可查

## 整体框架：一棵六层的知识树

```
 AI 知识树（110 词条）
├── 01-底层原理    AI 的地基（神经网络/扩散模型/Transformer/量化…）
├── 02-组件        模型的零件（UNet/VAE/CLIP/采样器…）
├── 03-表层概念    具体技术（量化格式/微调/加速/模型厂商/模型家族…）
├── 04-LLM工程     LLM 落地（推理引擎/提示词工程/RAG 工程/评测…）
├── 05-Agent工程   Agent 开发（框架/ReAct/多 Agent 协作/记忆…）
└── 06-IT行业      一切的地基（编程语言/操作系统/框架与库…）
```

从根往下读是一条完整的学习路径，从叶子跳入是速查。

## 技术形态

- **纯静态站**：内容就是 Markdown 文件，无服务器、无数据库、零维护成本
- **自动部署**：推送到 GitHub 即自动构建上线
- **可演进**：未来用户共创阶段，靠 GitHub 的 Issue/PR 实现动态交互（不需要自建后端）
