# 社区参考采集清单 — 第三批前置任务

> 原则：内容不能全靠训练数据（2025 年中截断）。每个词条的来源、定义、争议、
> 最新进展，优先从社区一线抓取：GitHub Issues/讨论、Reddit、HuggingFace 讨论区、
> 官方文档更新、arXiv 最新论文。

## 采集渠道（按优先级）

| 渠道 | 怎么采 | 适合什么 |
|------|--------|---------|
| GitHub 仓库 Issues/Discussions | API 搜 repo + issue | 模型官方讨论、已知问题、社区方案 |
| Reddit (r/StableDiffusion, r/LocalLLaMA) | JSON API (reddit.com/r/X/new.json) | 社区实践、踩坑、模型口碑 |
| HuggingFace 模型卡 discussion | HF API | 模型细节、格式争议 |
| arXiv 最新论文 | arXiv API | 技术源头、最新进展 |
| HF 趋势榜 | HF API trending | 新模型/新概念发现 |

## 执行方式

1. 每批词条生产前，先跑采集脚本（curl/API），把真实讨论存到 `采集/采集/` 目录
2. 生产单里附上采集到的来源链接 + 社区观点摘要
3. Kimi 成文时：定义/原理以权威源为准，争议/应用参考社区讨论
4. 每个词条的 sources 里，社区链接与官方链接并存
